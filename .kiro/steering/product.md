# Product Overview

## Purpose
PEXA Exchange Data Platform - Models data from PEXA Exchange source systems, applying business logic, protecting sensitive information, and creating documented models ready for analysis. Serves data engineers, analysts, and downstream systems requiring clean, governed data.

## Key Features
- **Medallion Architecture**: Raw → Stage → Curate → Data Services layers
- **SCD2 Historical Tracking**: Maintains complete audit trail of data changes
- **PI Data Governance**: Comprehensive tagging and masking of personal information
- **Multi-Source Integration**: Exchange, Projects, PexaKey, API Logs, Push Notifications
- **Environment Isolation**: DEV/STG/TEST/PST/PRD with proper promotion workflows
- **Data Quality Testing**: 15+ custom generic tests for data validation
- **Incremental Processing**: Optimized for large-scale data transformations

## Success Metrics
- **Data Quality**: >99% test pass rate across all models
- **Processing Performance**: <2hr daily batch completion
- **Coverage**: 100% of critical business entities modeled
- **Compliance**: Zero PI data exposure incidents
- **Availability**: 99.9% uptime for data services layer
